# Nano Banana Bot

![Nano Banana Bot Banner](https://placehold.co/600x200?text=Nano+Banana+Bot)

## Обзор
Nano Banana Bot — это Telegram-бот с интегрированным Mini App (Web App), который использует нейросеть **Nano Banana** от Google для генерации высококачественных изображений. Бот позволяет пользователям настраивать параметры генерации (соотношение сторон, разрешение), вводить промпт и прикреплять референсные изображения.

## Возможности
- **3 Мощных Режима**:
  - `⚡ Flash`: Быстрая и экономная генерация (Gemini 2.5 Flash).
  - `🍌 Pro`: Продвинутый режим с поддержкой диалога и высоким качеством (Gemini 3.0 Pro).
  - `📸 Imagen`: Фотореалистичная генерация (Imagen 4 Fast).
- **Web App**: Удобный UI для настройки параметров (AR, разрешение) прямо в Telegram.
- **Система Подписок и Валюты**:
  - Внутренняя валюта **NeuroCoin (NC)** для оплаты генераций.
  - Тарифы: **Демо** (бесплатно), **Базовый**, **Полный**.
  - Управление балансом и тарифами через бота.
- **Инструменты**: Управление через кнопки и команды, поддержка референсов (Image-to-Image).
- **Админ-панель**: Удобное управление пользователями, начисление средств, статистика прямо в чате.

## Технический стек
- **Бот**: Python 3.11, [aiogram 3.x](https://github.com/aiogram/aiogram)
- **Web App**: React, Vite, CSS Modules
- **Интеграция**: Google GenAI SDK (Gemini API)
- **База данных**: PostgreSQL (via SQLAlchemy) + AsyncPG
- **Инфраструктура**: Docker Compose

## Запуск

1. **Клонировать репозиторий**:
   ```bash
   git clone https://github.com/DNStrokin/nano_banana_bot.git
   ```

2. **Настроить окружение**:
   Создайте файл `.env` на основе `.env.example` и заполните ключи API (Telegram Bot Token, Google API Key).

3. **Запустить через Docker**:
   ```bash
   docker-compose up --build
   ```

## Обновление Web App
Чтобы обновить веб-приложение на GitHub Pages, используйте автоматический скрипт:
```powershell
.\deploy.ps1
```
*(Скрипт собирает проект и пушит в ветку `gh-pages`)*
